# FEISU v5.0.2 · 保存简化版 R4

本版修复打开新单按钮不可用，并把换单前的四个选项简化为三个。

- **打开新单**：当前盘点自动保存成功后，直接切换。无需另存文件，也无需再次确认保存。
- **另存备份**：可选，把当前盘点另存为 JSON 文件，包含商品、图片、已盘数量和列设置。操作后仍停留在弹窗，是否换单由你决定。
- **继续当前盘点**：取消换单，继续原来的工作。

自动保存和文件备份用途不同：前者方便随时接着盘点，后者便于另留一份文件。文件分享取消、失败或没有返回，都不会锁住“打开新单”。自动保存失败时保留当前盘点，不切换。

历史最多保留最近保存的50份；达到上限后清理最久未保存的记录，刚保存的旧单可以继续恢复。浏览器网站数据被清除时，浏览器历史也会被删除；需要长期留存的盘点请另存文件。

更新与iPad操作见 [iPad使用说明.md](iPad使用说明.md)。改动和验证范围见 [R4修复说明.md](R4修复说明.md)。
