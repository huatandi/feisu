2) https://github.com/huatandi/feisu → Add file → Upload files → 粘贴进去 → Commit changes

R26 修两件事

一、开镜先糊 1–2 秒（对焦慢）
原因：手机后摄的自动对焦每次都要从“无穷远”扫到 10–20cm，这段过程画面是糊的。
修法：
1) 开镜后立刻切到 single-shot 强制它做一轮完整 AF 扫描，再切回 continuous
   （比干等它自己慢慢收敛更快）。
2) 开镜后 200 / 500 / 900 / 1500ms 各“催”一次对焦
   （重新 apply 约束会触发新一轮 AF）。
3) 原有的 80ms 催焦保留，并扩到 80/320/700/1300ms。
效果：不能消灭 AF 本身的物理耗时，但能把它从“自己乱找”变成“立刻开始找”，
      明显缩短糊的时长。点一下取景框也能手动催焦（沿用原功能）。

二、成功扫码后，再点“扫码”要点两次
原因：上一次扫描的 scanning 状态没清干净，按钮只弹一句“扫描器已在运行”，
      不真的开相机；要点第二次才生效。
修法：
1) 点击时先检查相机是否真的活着（有没有 live 的视频轨道）；
   没有就判定为“状态卡住”，自动复位后立刻重开 —— 一次点击就出画面。
2) 上一次关相机后 350ms 内立刻再开，iOS 会抛 NotReadableError；
   现在会等这 350ms 内的剩余时间再要相机，避免第一次点击失败。
3) 启动失败时一定把状态复位，不会留下“卡住”的局面。
