R31 两项

一、按钮条再上移一点
--kb-gap 由 58px 调到 74px（键盘高度 + 74px）。
也就是比 R30 再往上 16px。表格滚动预留同步调整。

二、保活功能现在可以“自证”
R30 的诊断里只有一个 warm: true/false，看不出到底复用没复用。
R31 改成：

  "warm": { "active": false, "holds": 3, "reuses": 2 }

- holds：把相机保活了几次（每扫完一个商品 +1）
- reuses：保活的流被真正复用了几次（每复用一次 +1）
- active：当前是否正在保活

怎么判断保活是否生效：
- 连扫 3 个商品后点「📊 复制诊断」：
  holds 应该 ≥ 2，reuses 应该 ≥ 1（说明第二次开扫复用了热流）
- 如果 holds 在涨、reuses 一直是 0 → 复用没生效，把诊断发我，我去查开扫流程。
- 如果 reuses 也在涨，但画面仍然糊 → 说明流虽复用、镜头对焦状态仍被系统重置，
  那我就改成“关闭扫描时不退出取景界面”，让相机始终处于可见预览状态。

包含之前版本（R20–R30）：
后台线程解码、canvas 取景、iPad 框上移、低对比拉伸、扫描线 0.6s、
重开不残留、一次点击即可开扫、按钮条贴辅助条、相机保活 20 秒。
