FEISU v5.1.25 R41 —— 上传专用（只含网站运行文件）

三步：
1) 解压到桌面 → 进到文件夹里面，Ctrl+A 全选，Ctrl+C
2) https://github.com/huatandi/feisu → Add file → Upload files → 粘贴进去 → Commit changes
3) 等 1 分钟，打开 https://huatandi.github.io/feisu/js/core.js
   第一行应是 var VERSION = 'FEISU v5.1.25 · R41';

R41 改了四件事

一、数量没填：真的挡住，不再能跳过
R40 之前有“3 秒内再点一次可跳过”，你实测发现提示红色却照样开相机。
R41 删掉这个跳过通道：没填就是不让扫，提示改为「填写后才能扫下一个」。
填上后红色自动消失，可以直接扫。

二、工具条收进 ⚙️
「⚖️ 均衡 / 📊 复制诊断 / 🧩 电子单辅助 / ⚡ 连扫计数 / 🔦 补光」
现在默认藏起来，只留一个「⚙️ 设置」，点一下展开，再点一下收起。
（取景框下方那条提示文字保持不变。）

三、后台解码线程（worker）为什么没起来，现在能看到原因
你上一份诊断：worker.on=false、frames=0、error=null →
说明 new Worker(...) 一调用就抛异常，而且连 onerror 都没触发。
R41：把构造失败的原因写进诊断（worker.error = "ctor:错误名"），
并且 3 秒后自动再试一次（页面刚加载时资源没就绪属于瞬时失败）。

四、倾斜扫描降耗
- 旋转画布上限 700 → 560（省 36% 像素，条码在框里足够大）
- 不再每次尝试都转：连失 6 次后，每两次才转一次（保留一半横平尝试）
- 记住的角度保留更久（连失 40 次才丢）

关于你的 sharp:10
诊断里 view.sharp=10，表示画面是糊的（>20 才算对上焦）。
模糊状态下任何角度都解不出来——这才是倾斜读不出的根本原因。
如果 R41 之后 sharp 仍然长期 <15，说明这台机器的对焦确实慢，
建议扫的时候先在 20cm 左右停一下、等它对上，再靠近到 10–15cm。

验收：
1. 角标 v5.1.25 · 框内识别版 R41
2. 没填数量点扫码：相机不开、该行标红、提示要填
3. 取景界面底部只剩「⚙️ 设置」，点开能看到原来的四个按钮
4. 诊断 worker.error：若 worker 仍起不来，这一格会给出具体原因
