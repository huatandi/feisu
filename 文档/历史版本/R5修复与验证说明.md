# FEISU v5.0.2 R5 修复版

在原 R4 项目上修改，保留原界面、数据模型、保存/换单和历史记录逻辑。原包内说明仅作为项目资料。

## 已修复
- ExcelJS 读取包含空白行的工作表时，稀疏数组导致表头检测访问 undefined 并报错。
- 数据已解析成功后，图片提取失败不再阻断商品导入；显示图片读取警告。未能读取的图片不会保存到新单中，原 Excel 文件不变。
- 本地服务器原先只允许 Quagga vendor 文件，ExcelJS 请求为 404；新增所需脚本的明确白名单。
- Excel/CSV/ZXing 主库改用原版本随包文件，附许可证，降低 CDN 失败风险。Tailwind 样式及 WASM 增强仍有网络依赖，不能视为完全离线版。
- 修复部分设备首次未返回 pointsOfInterest 时，支持的对焦请求也被提前拒绝的问题；仍检查返回设置，避免谎报成功。初始化尝试框中心对焦，保留连续自动对焦、点击辅助对焦。
- 修复关闭/重开扫码后旧回调处理新会话、重复启动重置会话，以及切镜头未依据实际活动镜头的问题。
- 增加局部对比度处理，帮助应对包装造成的亮暗不均；调整增强触发时间。
- 原有倾斜识别、Quagga 双帧电子单校验保持；新增本地 ZXing 旋转区域恢复，WASM 加载失败或等待网络时也能尝试。限定与原主扫码器一致的一维条码类型，未采用猜测补全数字。
- 更新脚本缓存版本与页面版本标识。

## 已验证
- 原有保存/换单/文件备份/历史裁剪回归：15/15。
- 新增 tests/import-scanner.cjs：真实 XLSX 的前置空白行、中间空白行、富文本、文本条码前导零、源行号映射；模拟对焦支持与忽略场景、object-cover 区域坐标。
- Chromium 页面加载：XLSX、ZXing、ExcelJS、ScannerAdapter 均可用，无页面脚本异常。
- Chromium 实际调用新增本地 ZXing 恢复路径，成功识别生成的 EAN-13 条码 5901234123457。此测试不代表真实包装/相机效果。
- JavaScript 语法检查通过。

## 使用与验收
解压至新目录后，用原来的启动方式打开；静态部署需上传完整目录，包含 vendor。沿用原域名及浏览器存储，避免误以为历史盘点丢失；更换文件前建议通过原系统另存盘点备份。不要把空白的历史记录目录覆盖到已有历史目录。

iPhone/iPad 摄像头需在 HTTPS 下运行（手机访问电脑的普通 HTTP 地址通常不可用）。Safari 是否开放指定对焦点、变焦和补光取决于机型与系统；网页不能保证控制硬件微距镜头。请分别检查首次启动、点击对焦、切镜头、关闭重开、倾斜 15/30/45 度、透明塑料包装和反光场景。强反光遮住条纹的信息无法由算法恢复，可轻微改变角度或关闭补光。

尚未在实体 iPhone/iPad 上测量扫码速度或成功率，不能承诺特定提升幅度。当前未提供会报错的 Excel 样本，已修复代码中可复现的原因，但不能确认覆盖全部供应商文件；如仍失败，需要原始失败文件和完整提示定位。数字类型且未保存前导零的条码，无法凭空恢复前导零。

回归命令：node tests/save-switch.cjs；node tests/import-scanner.cjs。
